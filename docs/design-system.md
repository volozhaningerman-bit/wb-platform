# Design System v0.4

Цель:
Интерфейс профессионального инструмента для WB селлеров.

Принципы:
- чистый SaaS без шаблонности
- высокая читаемость
- минимум визуального шума
- быстрый доступ к данным

Основа:
- светлая тема
- карточки
- тонкие границы
- акцентные состояния

Будущее:
- dark mode
- анимации
- графики Recharts
